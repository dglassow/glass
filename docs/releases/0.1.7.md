# Glass 0.1.7

Important: moving from 0.1.6 to 0.1.7 is a one-time disruptive backend migration.
Close or park live terminal and agent work before installing this release.
After 0.1.7 installs the persistent `glassd` service, ordinary Viewer and app updates preserve terminal sessions and agent processes.

- Adds the Agent Board for concurrent Etch, Codex, Claude, and configured generic runs across devices.
- Makes Etch the primary structured provider while keeping explicit reduced adapters for older or limited provider surfaces.
- Reports the provider adapter Glass actually proved usable, with content-free diagnostics in the new Doctor panel.
- Keeps Hub metadata free of prompts, responses, approvals, commands, tool payloads, and transcripts.
- Reconciles stale run cards after a sessiond restart and offers provider-native resume when the provider exposes a session id.
- Moves backend ownership out of the app into a persistent per-user service, with blue-green Agent replacement and session-preserving routine updates.
- Stages stable controller and bundled Node updates for explicit application, validates the replacement, and rolls back an unhealthy controller.
- Adds release provenance, clean-tree and tag binding checks, an ARM64 macOS release-candidate build, and a live three-provider smoke gate.

Known limit: explicitly restarting or reconfiguring sessiond interrupts its live provider processes until sessiond-to-sessiond file-descriptor handoff is implemented.
Glass labels those runs interrupted and preserves their provider resume references when available.
